# Resident 2026 · Field Companion

**Приложение-дополнение для очных НРИ-сессий**, а не виртуальный стол: участники сидят рядом, общаются и бросают реальные кубики по желанию. На телефоне или ПК у каждого свой интерактивный чарник; мастер ведёт сцену, инициативу и заметки. Адаптировано для desktop и телефона; устанавливается как PWA на Android и Windows.

**Статус:** первая альфа. Нужен Node.js сервер. GitHub Pages не подходит — для аккаунтов и синхронизации необходим backend. Отдельный APK пока не создан.

## Возможности

- Аккаунты с логином и паролем, HttpOnly-cookie, salted scrypt-хеши паролей.
- **Одна общая кампания на всё приложение.** Первый зарегистрированный участник инициализирует её и становится мастером. Остальные входят по коду приглашения. Нет списка кампаний и переключения между ними. Дополнительные мастера назначаются создателем.
- Онлайн-чарник: 9 атрибутов, распределение 5/4/3, навыки, способности, инвентарь, биография, личные записи.
- Физические и психологические ранения: тупые и летальные, автоматический расчёт максимума здоровья.
- Броски d10: 1 = −1 успех, 8–10 = +1, 10 добавляет куб, критические исходы.
- Сложность задаёт мастер для сцены.
- Синхронизация событий, бросков, чарников, сцены и инициативы через Server-Sent Events.
- Пульт мастера: сцена, сложность, закрытые заметки, скрытые NPC, инициатива, приглашения, роли.
- Mobile-first интерфейс, PWA и краткий справочник правил без спойлеров.

## Запуск

Требуется Node.js **22+**. Дополнительных npm-зависимостей нет.

~~~bash
git clone https://github.com/ivan-s-2001/resident-2026.git
cd resident-2026
npm start
~~~

Откройте http://localhost:3000. Зарегистрируйтесь: **первый пользователь** один раз создаёт единую кампанию, получает права мастера и приглашает остальных по коду. Все последующие игроки после входа сразу попадают в свой чарник; если их ещё не пригласили, они видят экран ввода кода. Создать вторую кампанию нельзя, это запрещено сервером.

Разработка: npm run dev. Проверки: npm run check && npm test.

## Docker + HTTPS

~~~bash
docker build -t resident-2026 .
docker run -d --name resident-2026 --restart unless-stopped \
  -p 127.0.0.1:3000:3000 -v resident26-data:/app/data resident-2026
~~~

Для доступа с Android или другого ПК используйте reverse proxy с HTTPS (Caddy или Nginx с TLS).

Пример Caddyfile:

~~~caddyfile
resident.example.com {
  reverse_proxy 127.0.0.1:3000
}
~~~

Dockerfile выставляет NODE_ENV=production. Не размещайте сервер в интернете через обычный HTTP. Нужны резервные копии Docker-тома /app/data.

Приложение пока хранит аккаунты, чарники и одну кампанию **в одном JSON-файле**. Это MVP для одной инстанции сервера и небольшой группы. Для production с большим количеством пользователей перейдите на PostgreSQL.

## Права доступа и материалы хроники

- Все API проверяют аккаунт и участие в кампании.
- Заметки мастера и скрытые NPC защищены на сервере, не только спрятаны в интерфейсе.
- Личные заметки персонажа читают владелец и мастер.
- В публичный репозиторий **не загружены** сюжетные секреты из исходного архива.
- Для публичной эксплуатации рекомендуется регистрация по приглашениям, восстановление доступа, прокси-rate-limit и база данных с резервным копированием.

## Быстрый старт за столом

1. Мастер инициализирует единую кампанию, приглашает игроков, задаёт сцену и сложность.
2. Игрок регистрируется, вводит код приглашения и создаёт оперативника. При следующих входах приложение открывает эту кампанию сразу.
3. В чарнике заполняет атрибуты, навыки, снаряжение, отмечает ранения.
4. На экране чарника выбирает атрибут и навык, бросает кубы. Сервер считает успехи и отправляет результаты в журнал.
5. Мастер управляет инициативой, сценами и закрытыми записями.

## Использованные правила

Из предоставленного Obsidian-архива «Резидент 2026»: создание персонажа, атрибуты, навыки, броски d10, здоровье, боевые действия. Справочник содержит сокращённые игровые правила без материалов хроники.

В основных правилах навыки и предметы получают общий бюджет 21 очко, хотя старый PDF-чарник использует 18. За основу принят основной текст. Стоимость способностей задаёт мастер.

## Дальнейшая разработка

- Статусы, стресс, патроны, оружие, броня, критические повреждения.
- Одобрение изменения характеристик мастером и история чарника.
- Индивидуальные проверки, расширенная механика боя, автоматический подсчёт бросков от предметов.
- Библиотека материалов мастера с индивидуальным доступом игроков.
- Android APK через Capacitor после стабилизации PWA.
- Офлайн-редактирование чарника с очередью синхронизации на случай нестабильного Wi-Fi в клубе.
- Необязательная запись результатов физических кубиков — цифровые броски не должны быть обязательными.
- PostgreSQL, миграции, интеграционные тесты, восстановление учётных записей.
